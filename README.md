# Access Database Trainer (9 клас)

Локальний інтерактивний тренажер з теми «Бази даних. СУБД. Microsoft Access».

## Запуск
1. Розпакуйте ZIP.
2. Відкрийте `index.html` у сучасному браузері (Chrome, Edge або Firefox).
3. Заповніть реєстраційну форму. Сервер не потрібен.
4. Прогрес автоматично зберігається у LocalStorage цього браузера.

Для повністю офлайн-режиму відключіть інтернет: шрифт має системні запасні варіанти, усі вправи й ілюстрації вбудовані у проєкт.

## Публікація на GitHub Pages
1. Створіть репозиторій GitHub, наприклад `access-database-trainer`.
2. Завантажте в корінь репозиторію `index.html`, `style.css`, `script.js`, `README.md` та папку `assets`.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)`, натисніть **Save**.
5. Через кілька хвилин сайт буде доступний за адресою `https://ваш-логін.github.io/access-database-trainer/`.

## Для учня
- Спочатку зареєструйтеся. Обов’язкові поля: прізвище, ім’я та клас.
- Вибирайте модулі зліва, виконуйте вправи й натискайте «Перевірити».
- Спроби та час записуються автоматично. Можна повторювати відповіді.
- Для нового незалежного проходження натисніть «Нова спроба». Попередня історія не видаляється.
- Звіт можна переглянути або надрукувати у PDF: натисніть «Сформувати та завантажити звіт PDF», у вікні друку оберіть **Зберегти як PDF**.
- JSON-експорт дає змогу перенести результати на інший комп’ютер.

## Для вчителя
- Кнопка «Учитель» відкриває панель після введення пароля.
- Початковий пароль: `teacher9`. Змініть `TEACHER_PASSWORD` у `script.js` перед використанням.
- Панель показує проходження, час, кількість спроб, найчастіші помилки; підтримує експорт JSON/CSV та імпорт JSON.
- Щоб зібрати роботи з різних комп’ютерів, учні передають учителю JSON-файли, які імпортуються в панелі.

## Важливі технічні зауваження
- Це статичний клієнтський застосунок. LocalStorage прив’язаний до браузера/пристрою; для централізованого збору даних потрібен сервер.
- Пароль учителя у JavaScript не є справжнім захистом: його можна побачити в коді. Для реальної автентифікації потрібен сервер.
- PDF формується через `window.print()` і системний діалог браузера. Це офлайн-сумісний спосіб зі збереженням української мови: у діалозі друку оберіть «Зберегти як PDF». Автоматичне пряме створення PDF-файлу без діалогу та вбудований TTF потребують додаткової бібліотеки/шрифту.
- Таймер рахує час, коли вкладка активна. Після приховування вкладки відлік призупиняється; накопичений час зберігається.
- 25 вправ у п’яти модулях; оцінка обчислюється як `round(бали / 25 * 12)`.

## Оновлення дизайну
Інтерфейс оформлено у стилі Microsoft Office / Access: бордова акцентна палітра, стрічка-подібні панелі, картки та локальні SVG-ілюстрації для учнів 9 класу. Кнопка «Завантажити звіт» зберігає повний звіт окремим HTML-файлом із підтримкою української мови; його можна відкрити у браузері та за потреби надрукувати у PDF. Кнопка «Друк / PDF» відкриває системне вікно друку браузера.
